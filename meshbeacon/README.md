# ito

**Decentralised connectivity for your home.**

ito runs a private [Reticulum](https://github.com/markqvist/Reticulum) node on your Home
Assistant device, using the unmodified Reticulum reference implementation.

> **Experimental — local prototype.** Not yet published. Build and install it as a local app;
> see the Documentation tab. Not affiliated with the ito disaster-response project
> (meshbeacon.org).
