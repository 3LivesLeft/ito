# v0.6.0 Nomad Network pages: local test results

22 November 2026, branch `claude/quirky-cray-sdiq2f` (based on `develop` at `3582c86`, 0.5.1).
Isolated networks only: loopback and containers with `--network none`; throwaway identities.
**Not performed:** Home Assistant OS / Supervisor installation and update, the Raspberry Pi
reference device, AppArmor enforcement, real iPhone/iPad hardware, and any public Reticulum
network. These remain maintainer acceptance checks before release.

## Observations

- The image grows from 29.1 to 32.8 MB compressed (amd64, stand-in base).
- The pages service is a further Reticulum client process; the Nomad Network daemon used about
  55 MB resident in the spike. Raspberry Pi figures are pending.
- A newly published page appears for others within a minute (the daemon re-reads its pages every
  minute); an unpublished one disappears at once.
