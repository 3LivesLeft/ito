# v0.2.0 acceptance review (18 Nov 2026)

Where v0.2.0 stands against its acceptance criteria, CI and hardware testing. Nothing is merged,
released or deployed. Criteria are defined in the [roadmap](../roadmap.md).

## 5. Known gaps and risks

| ID | Gap or risk | Status |
|---|---|---|
| G-1 | **Out-of-the-box usability not met:** the panel needs the integration to be installed (by copying a folder today) | Permanent objective; blocked by the Ingress security review. Simplest supported path below. The options are in [secure interface options](../research/secure-interface-options.md) |
| G-2 | The Supervisor (on `main`, Nov 2026) is moving apps from a token to a Unix socket for its API. `supervisor_api_tcp` defaults to `True` today, but a code comment says changing the default will reach installed apps. v0.2's discovery uses `SUPERVISOR_TOKEN` over HTTP | **[Recommendation]** v0.2.x: support `SUPERVISOR_SOCKET` (`/run/supervisor/api/supervisor.sock`) alongside the token, with an AppArmor rule for that path and tests. Watch the Supervisor release notes. This also removes residual RR-9a (the discovery POST crosses the bridge in plain HTTP; threat model T28, corrected 19 Nov 2026) |
| G-3 | Responsible disclosure about Ingress is pending (private report prepared) | Maintainer submits; public documents stay at summary level |
| G-4 | Earlier commits on the public branch contain more detailed wording about the Ingress hypothesis than the current documents | Maintainer decision: leave the history (it was framed as an open question) or rewrite it (needs a force-push) |

## 6. Simplest supported installation while Ingress is unavailable

| Path | Steps for the user | Status |
|---|---|---|
| **Manual copy** (supported today) | 1) Install the File editor app; 2) create `/config/custom_components/meshbeacon` and upload the folder's files (or use the Samba share app to copy the folder); 3) restart HA; 4) switch on the option in MeshBeacon; 5) Add | Works; about 5–10 minutes; no terminal, no YAML. Documented in [getting started](../getting-started.md) |
| **HACS custom repository** (prepared) | In HACS, add the repository URL as an Integration, install, restart, Add. If HACS is already installed, this is about 2 minutes | **Not offered**: making the repository an install source and promoting it needs the maintainer's approval ([HACS](../hacs.md)). It also only works once the integration is on `main` |
| Official Home Assistant integration (option E) | None: it ships with Home Assistant | Long term; human-led upstream contribution |

**[Recommendation]** When v0.2 is approved for wider testing, approve the HACS custom-repository
path for testers who already have HACS, and keep the manual copy as the documented fallback.
